## 启动

已有依赖时直接运行：

```sh
npm run dev -- --port 5190 --strictPort
```

打开 http://127.0.0.1:5190/ ，服务仅监听本机。更换端口会使用不同的浏览器本地存储；验证继续旧作品时请保持同一地址与端口。首次安装依赖可用 `npm ci --ignore-scripts`；没有新增依赖。原四参数原型保留于 `/legacy.html`，不作为当前教学验收入口。

## 验证

```sh
npm test
npm run build
npm run test:e2e
node scripts/verify-novice-record.mjs --workbench
```

独立复验使用隔离静态目录，避免共同开发目录热更新；5240、5238、5236、5234、5232及更早固定目录保持不变，重现命令见本轮交接。不同端口的本机存储彼此独立；原地址存档不删除。

Playwright 如未装默认浏览器，可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指向已安装的 Chromium。生产构建本地检查使用 `EQ_PREVIEW=1 npm run test:e2e`。控制器故障/冲突回归另用 `npx playwright test --config tests/ui/playwright.config.js --workers=1`；其中教学策略明确是测试替身，不冒充学生流程。
