# 工位风格与组件 token V0.3

方向：暖纸色的个人研发工位。通过员工证、邮件邮票、元件格、便签和工具面板形成职业游戏感；页面始终围绕一个客户委托和下一步动作。人物与场景是氛围，操作界面保持清晰的文字与可验证图形。

首张小样使用原创电子工作室与林工角色。用户补充授权直接调用图片工具继续制作首单素材，本轮沿用同一风格增加傍晚阅读角、独立林工和元件托盘。没有复用《深圳 I/O》的角色、文字、关卡或素材，也没有扩展到全商城资产。

## 颜色

| `--eq-surface` | `#fffdf7` | 邮件、表单 |
| `--eq-ink` | `#233e36` | 主文字 |
| `--eq-muted` | `#646e60` | 次级文字 |
| `--eq-line` | `#d9dbcb` | 纸面边线 |
| `--eq-green` | `#244b3d` | 主要动作、工作台边框 |
| `--eq-green-soft` | `#e7eddf` | 工程辅助区 |

| `--eq-coral-soft` | `#f9e4d8` | 温和任务强调 |
| `--eq-yellow` | `#f0d489` | 便签与工位道具 |

字体使用本机 `PingFang SC / Microsoft YaHei / system-ui`，代码与编号使用 `SFMono-Regular / Consolas / monospace`；不依赖在线字体。字号主要为 12–15px 的操作与正文、23–30px 页面标题、27–40px 场景标题；9–11px 用于非关键元数据。若现场投影或低分辨率显示器需要更大字体，应由总控统一调整 token/布局并复验。

## 布局与状态

- 桌面：顶部四个导航；左侧员工证与六段路线；右侧当前工作。内容最大 1550px，侧栏不会固定遮挡页面。
- 中等宽度：先收窄侧栏，再把双列卡片折成单列。
- 小于 700px：个人身份与步骤压缩成横向路线；顶栏保留手册、求助。工作台画布在自身容器滚动，整页不横向溢出。
- 当前阶段有数字、`aria-current` 和文字；未来阶段不冒充业务锁。已完成显示勾选，但该状态必须由调用方提供。
- 主动作墨绿实心，辅助动作纸色描边，轻动作文字加箭头。按钮默认不会触发表单提交。
- 绿色状态不自动代表已通过；标签必须写清“静态”“本地”“待校准”等具体含义。

## 可访问交互

原生按钮、select、textarea 与 dialog；表单 label 关联唯一 ID；页面 skip link；可见焦点环；页签左右键/Home/End；弹窗 Escape 与焦点返回；收入表格列头和行头；SVG 端子通过 HTML 按钮响应键盘，不把 SVG 文字充当不可读的图片标签。动画仅轻微 hover，尊重 `prefers-reduced-motion`。

实际验证了键盘行为和布局，未做屏幕阅读器实机验收或完整 WCAG 审计。头像替换、更多导航项及新硬件画布进入后需继续检查命名、对比度、窄屏和焦点。

## 资产边界

现有工位 JPG 为 1536×1024、536,502 字节。本轮增加阅读角 WebP（1672×941、212,526 字节）、透明托盘 WebP（1536×1024、324,386 字节）和透明人物 WebP（1175×1338、207,482 字节）。压缩不裁切、不缩放、不改画面；两张透明图的 alpha 逐像素保留。托盘保留半透明柔和投影，网页背景可透出。

生成图只服务场景、人物和道具；板卡外观为通用艺术形象，不能用于识别真实 Uno 型号或端子。引脚名、说明、线路和交互继续由 React/SVG 绘制；正式接线准确性由硬件专项负责。

使用已读取的 `imagegen` 技能与内置工具直接生成；具体型号未回传，不作为用户本轮要求的交付门槛，也不冒称型号。来源、完整提示词、文件摘要、尺寸及授权状态见资产 manifest。

## 探索模式

V0.3 以暮色研发室作为空间背景；深墨绿压住周边 UI，暖金标记可交互对象，纸色留给邮件与物品说明。与原纸面工位属于同一世界；不让技术编辑区变成生成图片。场景实际尺寸 1672×941，WebP 275,918 字节。热点百分比坐标仅属于场景，不属于硬件端子。

探索命名空间 `.eq-ui.eq-adventure` 提供 `--eq-world-bg:#132e28`、`--eq-world-panel:#19372f`、`--eq-world-gold:#e2c886`、`--eq-world-text:#f2eedc`。入场、热点与对话动效均短且有限，可通过界面或系统偏好关闭。详细审查、动作协议与验证见 `immersion-review.md`、`adventure-integration.md`。
