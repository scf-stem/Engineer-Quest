## 改造决定

1. 原创夜间研发室常驻；顶部身份/收入 HUD、底部工具栏、场景任务追踪器保持一致。首屏入职也在同一研发室。工具打开为大尺寸工作窗口，内部独立滚动；关闭/Esc 回原工位，重新打开保留草稿。接线和编辑空间优先，避免网站式标题占屏。
2. 邮箱变为委托档案 + 可见的四组方案选择，使用真实 radio 而非原生下拉。输入/判断/输出/重复构成任务结构；解释可编辑并提交，静态覆盖和语义核对状态明确区分。
3. 同一工具窗口内切接线、Blockly、代码、客户测试；保留现有运行器、版本失效、危险提示、快照和幂等账本，不从导航伪造结果。测试摘要优先给出具体失败/通过，完整断言和事件可展开。
4. 工程手册为有目录、搜索、节号链接、可操作示例与步骤的阅读器。首单软件必需章节补为可读内容；接线只说明当前虚拟候选模型，真实参数不编造。硬件定稿章节明确待完成。
5. 林工入口通过 `TutorialSlot` 接口暴露只读事实、`onNavigate` 和 `onOpenManual`；本分支不制作角色、剧情或在线 AI。独立专项可替换插槽，不取得提交/测试/结算权限。
6. 键盘快捷键仅在非输入区生效；Esc 先关闭模态层，再关工具。原生 dialog 限制焦点，关闭返回触发控件。支持窄屏、页面缩放、减少动效；不通过强制全屏权限实现布局。
