## 真实连接与退路

精确目标现同时列出值槽、`VARIABLES / SETUP / LOOP` 等语句输入、`DO0 / ELSE / BODY / DO` 等分支输入，以及每条语句的前面/后面。既有值目标 ID 不变。原生拖动仍使用 Blockly 的连接检查、吸附与插入标记；选定语句边界时，上下两侧的原生等价口均可吸附。取消目标后恢复自由拖动。目标不产生学习或通过事实。

“点选移动 / 插入”是逐块操作：选择已有块或从当前托盘拿一块，选择目标，预览，再确认。默认“只移动这一句，分支随行”：将该句从原位置取出，把原上下句接回，再插入目标并保留目标原下句。还可明确选择“这一句和后续整串，分支随行”。不会自动补完整解答，托盘里的新块与原拖出块使用相同默认字段。

单句移动只把自身输入/分支视为随行子树，因此把 if 移到它原来的 next 链后面合法；把 if 接到它自身、DO 内部或所带分支里的某句仍被拒绝。整串移动则拒绝其全部后续内部的目标。`placeBlock` 只操作实际 Blockly 连接，所有断开/接回/连接放在一个原生事件组中；撤销调用 `workspace.undo(false)`，没有通过重载序列化伪造撤销。

原值槽的类型检查、精确选择与显式替换许可保留。点选替换先展示将替换哪个值，取消不改作品；确认后旧块仍留在工作区，可撤销。若不再使用旧散落块，提示选中按 Delete 或拖到垃圾桶，不自动删除用户作品。预览记录当时的实际序列化；确认前作品发生变化时要求重新预览。

工具栏、目标和退路控制在 1120px 内，3440 宽度不会把确认操作推到另一端。托盘打开时优先保证选中的连接口可见；没有精确目标且主程序能容纳时才平移程序体，避免托盘遮挡。视口变化不改序列化坐标。

## 宿主兼容与可见操作

`ProgramBlocks` props 不变。`onChange` 仍返回 `{origin,program,workspace,error}`；初始化为 `initialize`，外部恢复为 `external`。实际编辑和撤销均为 `edit`，兼容现有宿主只保存 edit 的逻辑；按钮/快捷键撤销附加可忽略的 `action:'undo'`。相同工作区回传用规范 JSON 比较，不重建实例，不清撤销；真实外部不同快照才载入。只读切换使用同一工作区，也保留同会话撤销。

可见 UI 标签/定位如下，整合验收可直接使用，无需专项 setter：

| 操作 | 标签或 selector |
| --- | --- |
| 打开逐块退路 | 按钮 `点选移动 / 插入` |
| 选已有 if | select `aria-label="选择要移动或插入的积木"`；已有项以 `如果 · …` 开头 |
| 选语句范围 | select `aria-label="移动语句的范围"`；默认 `只移动这一句，分支随行` |
| 选读取之后 | select 保留 `aria-label="准备接入的精确槽位"`；典型项 `变量赋值 1 · 后面（原下句保留）` |
| 等价插入目标 | 同一 select，典型项 `等待 1 · 前面（插到本句前）` |
| 选分支 | 同一 select，`如果 1 · 如果分支（空）` / `如果 1 · 否则分支（空）` |
| 预览、确认、取消 | `2 预览连接` → `确认连接` / `确认替换` / `取消预览` |
| 取消精确锁定 | `取消目标` |
| 撤销 | `撤销一步`，或组件内 Ctrl/Cmd+Z |

`block-connections.js` 保留既有 exports，增加内部可测试的 `listConnectionTargets / targetConnection / connectionKey / targetBoundary / placementDecision / placeBlock`；不涉及执行器 IR 或评分接口。
