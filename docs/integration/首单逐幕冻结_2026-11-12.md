## 共享状态与身份

- 真实作品、D原始响应、A实际操作、B连线、客测、账本继续存原控制器；剧情只有 `presentation.journey`（场景、句号、暂停与已读幕）。它不能承载 passed 或收入。
- 新员工必须自动进入00；旧存档无 journey 时继续原作品，不强制重置课程或发新人奖励。可主动开启/重看带教。
- 重看培训仅重播角色与已学介绍，不创建员工、不重做订单、不撤学习。重做订单保留员工、旧尝试与收入，新尝试从接单开始。返回员工选择先保存本页；保存失败停在原工位，提供备份/重试。
- 多员工使用同一浏览器的独立记录键，原 `workspace` 键原地保留；各自昵称、剧情、作品、订单和收入隔离。目录只保存选择与显示名，不成为通过权威；跨页冲突沿用真实版本检查。
- 对话推进先保存再转场。暂停、合手册和刷新能回到原句/动作；手册导航不生成观察。

## 界面与供料

新员工屏幕只给当前主动作。工具随介绍加入工具柜；未开放工具说明用途/时机并留在原位置，不静默改跳。移除新主线中的重复四页签与常驻委托侧栏；已介绍的工具允许回访。动手模式把人物收至边缘，目标、装置、结果优先；1280×720和1440×900实际检验。

学生默认先看当前图卡/页，全文目录是二级查阅。研发解释、教师答案不作角色台词或默认学生目录。原六册及完整答案保留在资料详情，不删作者文件；新任务书完成前先由整合层提供与真实动作一致的局部页，后续替换须核对节号/端子/按钮。

视觉沿用夜间研发室与林工形象，先核对全屏报到与动手工位两张真实界面，再补同视角客户桌面/角色表情。图上不生成端子文字；灯与执行高亮由实际状态驱动。任务书隔离目录不修改，接口需求在本文件与实施交接中共享。

## 验收安排

阶段0冻结本文；阶段1入职到第一次操作；阶段2完整首单及界面减法。每步要记录实际版本与操作证据。最后由未参与实现的 sub agent 用 computer use 空白完整体验，覆盖误点未开放工具、暂停返回、关手册、接错/修正、两种桌面尺寸、旧档与多员工恢复，整体无阻碍才通知用户。真实学生试教是后续验证，本轮不另设硬门槛。不部署。
