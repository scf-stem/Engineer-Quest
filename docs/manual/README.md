# Engineer Quest 首单工程手册

面向学生的首单阅读稿 **V0.2 · 本机软件体验整合版 · 2026-11-11**。从实际操作到查阅资料使用同一套节号。

1. 第一次做订单：[首单手册](首单手册.md)。按操作、预测、检查点逐段进行。
2. 忘了端子、语法或错误原因：[工程参考](工程参考.md)。按节号查，不必从头读。
3. 已经尝试，需要核对完整程序：[参考实现](参考实现.md)。这是答案附录，不是起步模板。
4. 教师准备实物：[教师实物附录](教师实物附录.md)。目前不能据此直接批准上电。
5. 维护者查证据：[来源与限制](来源与限制.md)。包含源码依据、UI 差异及尚未验证的项目。

本目录提供完整 Markdown、原创 SVG 和受限 C++ 示例，已接入应用内手册阅读器。没有 Word/PDF，也不宣称打印或实物验收完成。当前整合仍由开发者独立游玩核对；真实初学者试教尚未完成。

本稿借鉴工程资料册的“先做任务，遇到问题查资料，再回任务验证”的组织方式，不复制《深圳 I/O》的图、文案或汇编接口。这里使用当前项目的 Arduino Uno 候选引脚和简写 C++。
