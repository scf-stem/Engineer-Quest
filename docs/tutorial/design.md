# 林工教程设计 · 2026-11-11

首单中，林工是负责带新人的硬件同事。讲话具体、平等，每句做一件事：交代客户场景、问一个可观察的变化，或指出下一项操作。玩家操作后再讨论证据，不靠连续好评维持剧情。零基础学生不需要先会代码拼写。

对话使用原创成年工程师立绘、短句文字框、逐字显示及明确的“显示整句 / 下一句”。选择题只提供局部概念反馈，不评判自由文本。学习顺序是做什么→为什么→自己做→如何验证；不自动装载接线或完整程序答案。玩家随时可收起、查看记录、重看本节、跳过本节说明到操作目标。退出再进入保持教程位置，工程事实始终以宿主为准。

教程分为接单、方案、接线、积木、代码变更、软件交付六章。每章最多数句说明和一个练习判断，最后暂停等待真实业务。客户端教学记忆只保存看过的句子与局部选择，不保存“通过”。宿主报告变更时重新计算当前章；旧证据、错误接线优先于剧情。点击继续、选对答案、重看、快进均不能保存方案、修线、运行测试或结算。

表现参考 [Ren'Py 官方 Quickstart](https://www.renpy.org/doc/html/quickstart.html) 的 say/menu 表现与可读角色身份；在 React 中独立实现，不引入引擎或现有角色素材。对话不是恋爱系统，也不假装在线 AI。

接线依据现有 `UNO_CANDIDATE_PROFILE` 和 `validateWiring`。已重新核对 [UNO R3 文档](https://docs.arduino.cc/hardware/uno-rev3/) 与 [A000066 官方引脚图](https://docs.arduino.cc/resources/pinouts/A000066-full-pinout.pdf) 第一页：A0 为模拟输入，D9 为数字 IO，5V 与 GND 分别为电源与公共地。AO 读数低为暗、D9→串联电阻→LED A / K→GND 是当前虚拟关卡的约定；实际模块型号、方向、限流与 Uno 代际仍待现场核验，不授权上电。

角色：林工，原创成年男工程师，深蓝工装、眼镜、轻微青色仪器轮廓光，语气耐心、以现象和证据说话。首版一张中性带微笑立绘；严肃诊断由文字和颜色表达，避免表情切换分散技术注意力。图像生成工具未暴露可核实模型名称，不声称 Image 2。
