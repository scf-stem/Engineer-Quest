## 1. 公共值和版本

所有 ID 使用不透明字符串，时间用 UTC ISO 8601；时序模拟用非负整数毫秒。客户端不得自行赋予真实身份和权限。合成测试身份可显式标记 `synthetic:true`。

统一诊断：

```ts
type Diagnostic = {
  code: string; severity: 'error'|'warning'; message: string;
  nodeId?: string; terminalIds?: string[];
  sourceRange?: {start: number; end: number}; manualSection?: string;
};
type Ref = {id: string; version: string; digest: string};
type Result<T> = {ok: true; value: T; diagnostics: Diagnostic[]}
  | {ok: false; diagnostics: Diagnostic[]};
```

摘要算法与规范化序列化由 E 统一。前端内容摘要只用于草稿提示，服务端必须重新计算；不得把摘要当作权限凭证。

type TaskDefinition = {

## 3. B→A/E：设备、端子及接线

`DeviceProfile`：`ref`、`family:'arduino-uno'`、可空的 `variant`/`fqbn`、`calibrationStatus:'synthetic'|'pending'|'verified'`、端子清单（ID、方向、信号类型、范围）、逻辑端口至物理引脚映射、元件规则版本。

`WiringDocument`：`schemaVersion`、`deviceProfileRef`、`components[{instanceId,typeRef,position}]`、`connections[{id,from,to}]`。元件实例位置是显示数据，不改变电气连接。

B 导出：

- `validateWiring(document, deviceProfile): Result<ValidatedTopology>`
- `createInputFixture(profile, scenario): InputTimeline`（仅虚拟合成输入）
- 工作台组件 `WiringWorkbench({value,deviceProfile,onChange,diagnostics,readOnly})`

旧原型 `UNO.A0` 等命名只能由显式迁移适配器进入新结构；B 不直接改 `engine.js` 或另写程序执行器。A 消费已校验 pin map；引脚错误返回诊断，不自动替学生重新接线。

## 4. A→E/B：简写 C++、积木与确定性执行

A 提交 `ProgramIR` JSON Schema 候选，至少含 `schemaVersion`、`languageProfileRef`、节点 ID、变量/常量/比较/条件/输入/输出/等待/主循环。语句与表达式类型、整数范围、采样时点、输出保持、等待语义和预算必须写清。简写函数须固定展开为真实 Arduino C++，不得调用模型翻译。

建议接口：

- `parseShortCpp(source, languageProfile): Result<ProgramIR>`
- `blocksToProgram(blockState, languageProfile): Result<ProgramIR>`
- `validateProgram(program, deviceProfile): Result<ValidatedProgram>`
- `generateArduino(program, deviceProfile): Result<{source,map,toolchainRequirements}>`
- `simulate(program, topology, inputTimeline, limits): Result<SimulationResult>`
- `evaluate(simulationResult, customerTests): TestRunDraft`

`SimulationResult` 包含 `status:'completed'|'budget_exceeded'|'runtime_error'`、`events[{atMs,step,nodeId,variables,outputs}]` 和诊断。`TestRunDraft` 引用确切程序、接线、需求、测试集与设备版本；实际服务端证据由 E 签发。A 不判断奖励、不改变订单需求。

文本进入时保存积木快照；返回积木需要明确查看旧快照/新分支，不能静默覆盖文本。旧四字段 AST 用单向迁移函数，保留旧版本，不原地伪装新结构。

## 5. E：个人提交、评审和教师状态

`SubmissionSnapshot` 建议：`id`、`ownerStudentId`、`taskRef`、`requirementRef`、`programRef`、`wiringRef`、`deviceProfileRef`、`testSuiteRef`、`manualRef`、`sourceDigest`、`createdAt`、`revision`。不含 teamId；owner 由服务端会话确定，不能信任请求体。

阶段证据分别为需求提交、接线检查、软件测试、编译、上传工具结果、安全签核、功能验收。证据均绑定快照版本；变化令依赖证据过期但保留历史。现阶段编译/烧录可显示未实现，不造成功记录。

NPC 请求只包含最小课程/快照/测试证据和合成学生解释；输出 `mode:'ai'|'static'`、`question`、`citations[{ref,path}]`、`suggestedNextStep`、`needsTeacherHelp`。NPC 不写阶段通过、钱、库存、教师批准。当前 `npc.js` 本地 provider 仅是适配壳，实际模型接入归 E；未获授权不传真实学生资料。

教师安全检查与功能验收独立实体；真实验收仅由已鉴权教师发起，校验个人作品范围与版本，不以网页按钮点击证明硬件。
